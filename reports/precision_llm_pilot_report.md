# LLM 정밀 분류 소규모 파일럿 결과

## 실행 범위

- 입력: 로컬 `라벨링.xlsx`
- 챕터: `inflation` / `물가와 인플레이션`
- 모델: `openai/gpt-5.6-sol` via OpenRouter
- OpenRouter 응답 `model` 메타데이터: `openai/gpt-5.6-sol`
- 샘플: 10건
- 구성: 키워드 후보 5건, 키워드 비후보 5건
- 실제 LLM 호출: 10건
- API 실패: 0건
- 원문·확정 골드 라벨은 모델 입력에 포함하지 않음

이전 모델로 프롬프트를 검증한 뒤, `openai/gpt-5.6-sol`로 10건을 실행했습니다.
현재 결과 파일은 이 모델의 마지막 10건 실행 결과입니다.

## 응답 검증 결과

- JSON 스키마 검증 통과: 10건
- 원문 근거 구간 검증 통과: 9건
- 근거 검증 실패로 추가 검토: 1건
- `needs_review=true`: 1건
- 최종 `review_status=PENDING`: 10건
- 모델이 반환한 참고용 상태: `PENDING` 6건, `REJECTED` 4건

모델이 `APPROVED`를 반환한 경우에도 자동 승인하지 않습니다. 문제 생성에
사용하려면 별도의 Human Review를 거쳐야 합니다.

## 토큰 및 점수 관찰

- 입력 토큰 추정 합계: 7,224
- 출력 토큰 추정 합계: 1,653
- 입력 토큰 평균: 829.4
- 출력 토큰 평균: 165.3
- 관련도 점수: 최솟값 0.0, 최댓값 0.98, 평균 0.28

이 점수는 모델의 루브릭 판단값이며 확률이나 Precision을 의미하지 않습니다.
현재 확정 골드는 독립적으로 합의된 평가셋이 아니므로 이번 파일럿에서는
Precision·Recall·F1을 계산하지 않습니다.

## 결과 파일

행별 응답은 원문을 포함할 수 있어 다음 로컬 무시 경로에만 저장합니다.

`data/labeled/precision/llm_pilot_results.jsonl`

다음 단계는 응답 근거와 점수를 사람이 검토하여 독립 골드셋을 만들고, 개발
샘플과 분리된 평가 샘플에서 임계값별 Precision·Recall을 계산하는 것입니다.
