# Excel 라벨 기반 정밀도 중심 EDA·파이프라인 결과

## 1. 실행 범위

- 입력 파일: `라벨링.xlsx`
- 입력 행 수: **160건**
- 챕터 기준: `inflation` / `DRAFT_NOT_CANONICAL`
- LLM 호출: **0회** (키워드 기준선과 라벨 품질만 오프라인 평가)
- 원본 Excel: 수정하지 않음

## 2. 데이터 EDA

- 기관별 건수: `{'KDI': 160}`
- 설명 문자 수: 평균 `325.8`, 중앙값 `279.5`
- 설명 토큰 수: 평균 `193.1`, 중앙값 `169.5`,
  총 `30901`
- 사용 토크나이저: `gpt-4o-mini` / `o200k_base`
- 단락 수: `{'count': 160, 'total': 160, 'average': 1.0, 'median': 1.0, 'min': 1, 'p25': 1.0, 'p75': 1.0, 'p95': 1.0, 'max': 1}`
- 골드 관련도 분포: `{'0': 98, '1': 55, '2': 7}`

## 3. 라벨 품질 결과

- 평가자 A·B 비교 가능 행: `49건`
- 평가자 A·B 일치율: `79.6%`
- 평가자 불일치: `10건`
- 자료 품질 `검토필요`: `7건`
- 문제 생성 적합성 열과 골드 정책 불일치: `0건`
- 튜터 검색 적합성 열과 골드 정책 불일치: `0건`
- 판정 근거와 본문 토큰이 겹치지 않는 행:
  `150건`

평가자 A의 라벨이 현재 골드와 동일하므로 A 기준 수치는 독립적인 모델 성능이 아닙니다.
평가자 B는 49건 중 10건이 달라 합의 검수가 필요합니다.

## 4. 키워드 후보 기준선

키워드 매칭은 최종 관련도 판정이 아니라 후보 수집 단계입니다.

| 전략 | 목적 | 후보 수 | Precision | Recall | F1 |
|---|---|---:|---:|---:|---:|
| 기본 키워드 | 문제 생성 | 4 | 100.0% | 57.1% | 72.7% |
| 확장 키워드 | 문제 생성 | 5 | 100.0% | 71.4% | 83.3% |
| 기본 키워드 | 튜터 검색 | 4 | 100.0% | 6.5% | 12.1% |
| 확장 키워드 | 튜터 검색 | 5 | 100.0% | 8.1% | 14.9% |

위 수치는 현재 Excel의 `확정 골드`를 기준으로 한 오프라인 기준선입니다.
독립적으로 합의된 평가 세트가 아니므로 최종 제품 성능으로 보고하지 않습니다.

## 5. 재구축한 사용 정책

1. Excel의 `확정 골드=2`만 문제 생성 후보의 양성 기준으로 사용합니다.
2. Excel의 `확정 골드=1 또는 2`는 튜터 검색의 폭넓은 검색 기준으로 사용합니다.
3. 키워드 미매칭 자료는 삭제하지 않고, 누락 후보 검수 큐에 남깁니다.
4. 문제 생성은 키워드 후보 → LLM 정밀 분류 → 출처·근거 검증 →
   Human Review 순서로 진행합니다.
5. `관련도 2`는 문제 생성 후보이지 자동 승인 상태가 아닙니다.

## 6. 우선 검수 대상

- 평가자 A·B 불일치 10건
- 자료 품질 `검토필요` 7건
- `기준금리`, `상품권`, `생산자물가지수`, `국제피셔효과`, `차이메리카`, `리플레이션`
- 확장 키워드 기준 문제 생성용 오탐·누락 사례

행 단위 후보와 검수 큐는 로컬의 `data/labeled/precision/precision_keyword_candidates.csv`와
`data/labeled/precision/precision_review_queue.csv`에 저장됩니다. 이 파일들은 원문을 포함할 수 있으므로
Git에는 올리지 않습니다.
