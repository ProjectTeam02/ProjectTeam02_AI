# 인플레이션 챕터 관련도 평가 계획

## 현재 상태

현재 저장소에서 최신 독립 골드 라벨과 `라벨링.xlsx`를 확인하지 못했습니다. 따라서 아래 문서는 평가 설계이며, Precision·Recall·F1 수치를 생성하지 않습니다.

## 평가 대상

평가 데이터는 `document_id` 또는 `chunk_id`, 원문, 표제어, 챕터 기준, 독립 라벨, 검수자와 검수 시각을 함께 보관합니다. 프롬프트 개발에 사용한 개발 세트와 최종 평가 세트는 문서 ID 기준으로 겹치지 않게 분리합니다.

인플레이션 관련도는 다음 0·1·2점으로 합의합니다.

- 0점: 인플레이션 학습과 직접 관련이 없음
- 1점: 배경지식으로 간접 관련되지만 핵심 설명 자료는 아님
- 2점: 개념·측정·원인·영향·대응 정책을 직접 설명하며 문제 근거로 사용할 가능성이 있음

현재 2점 표본이 적다면 직접 관련 자료와 혼동하기 쉬운 음성 사례를 의도적으로 보충합니다. 단순히 표본 수만 채우지 않습니다.

## 사용 목적별 이진화

| 사용 목적 | Positive | Negative |
|---|---:|---:|
| 문제 생성 | 2점 | 0·1점 |
| 튜터 검색 | 1·2점 | 0점 |

문제 생성은 관련도 외에도 출처 승인, 본문 근거, 사실성, Human Review 승인, `question_generation_allowed`를 모두 확인합니다. 튜터는 더 넓은 후보를 허용하되 검색 결과에 근거와 출처를 함께 전달합니다.

## 측정 지표

각 사용 목적별로 TP, FP, FN, TN을 계산하고 Precision, Recall, F1, Confusion Matrix를 기록합니다. 골드 라벨이 없거나 합의되지 않은 행은 지표 계산에서 제외하고 `UNVERIFIED`로 남깁니다.

```text
precision = TP / (TP + FP)
recall    = TP / (TP + FN)
F1        = 2 * precision * recall / (precision + recall)
```

## 오류 분석

FP와 FN은 다음 원인으로 태깅합니다.

- 키워드 과다 매칭 또는 연관어 누락
- 표제어와 본문 의미 불일치
- 챕터 경계가 모호함
- 원문 품질·출처 문제
- LLM 판단 오류
- 골드 라벨 오류 가능성

`기준금리`, `상품권`, `생산자물가지수`, `국제피셔효과`, `차이메리카`, `리플레이션`은 사람이 원문과 기준을 함께 보고 최종 라벨을 확정합니다.

## 임계값 실험

LLM 관련도 점수는 확률이나 정확도가 아닙니다. `relevance_score` 임계값을 0.60, 0.70, 0.80, 0.90 등으로 바꾸어 후보 수와 검수 표본의 Precision·Recall 변화를 비교하되, 독립 골드 세트에서만 최종 비교합니다. 키워드 필터의 점수는 후보 수집 신호이므로 같은 의미의 확률 실험에 사용하지 않습니다.

## 데이터 누출 방지

- 개발 세트로 프롬프트·키워드·임계값을 정한 뒤 최종 평가 세트는 고정합니다.
- 같은 `content_hash`의 JSON/JSONL 중복 행은 한 문서로만 평가합니다.
- 동일 문서의 다른 청크가 train/test에 나뉘지 않게 `document_id` 그룹으로 분리합니다.
- 실제 API 대량 호출 전에는 dry-run과 소규모 샘플만 실행합니다.
